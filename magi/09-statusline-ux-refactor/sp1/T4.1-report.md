## 關鍵決策

1. **頂帶＝`#preview-section` 自身接手 role/tabindex**（未另加一層
   wrapper div）：省一層巢狀 landmark，`id="preview-section"` 不變，
   skip-nav「跳至預覽」錨點與既有 tabindex 語意（-1→0）沿用，改造不
   衝擊 T4.3 範圍。
2. **z-index:5**（`.preview-section`）：介於一般內容（auto/0）與
   `.skip-link` 的 `z-index:10` 之間；兩者皆非嵌套於彼此的定位祖先內，
   實際比較發生在根層 stacking context，10>5 保證 `.skip-link:focus`
   恆浮頂帶上（未額外測試，純 CSS 數值比較，風險低）。
3. **`#output-section` 過渡就地留在 `<main>` 內**（原「已選擇」中欄與隱
   藏池之後），透過 grid-area `output` 跨欄置底——完全未改內部結構／
   id／live region，T4.2 收進 `<dialog>` 時直接原地包裹即可。
4. **segmented control 用 `:has()` 選擇器**做視覺選中態＋焦點環（技法
   同既有 `.color-swatch input` 視覺隱藏 pattern）：codebase 尚無
   `:has()` 前例，但屬純視覺加強（非功能性），退化路徑安全（不支援
   `:has()` 的瀏覽器仍看到功能正常、僅視覺選中態不明顯的原生 radio
   列）。
5. **可見文字縮短＋`aria-label` 承載全文**（WCAG 2.5.3 Label in Name）：
   情境四項可見縮寫（滿血／早期／條件／Windows）皆為原文字的前綴子字
   串，`aria-label` 內容與縮短前可見文字逐字相同，SR 播報內容零改變。
6. **mock 時鐘 hint 文字集中於 `main.ts` 常數 `PREVIEW_MOCK_CLOCK_HINT_
   TEXT`**（同 `VARIANT_LABELS` 慣例），未 import `messages.ts`（T5.x
   並行 lane 專屬檔案，本 task 依 brief 指示不耦合，先集中待 T5.5 全量
   遷移時改走 `t()`）。
7. **「產出腳本」佔位鈕**：`<a href="#output-section">` 錨鈕，置頂帶右
   端（`margin-left:auto`）；過渡期功能＝捲動並聚焦至 `#output-section`
   （該 section 帶 `tabindex="-1"`），與既有「跳至產出腳本」skip-link
   行為一致、不衝突。T4.2 直接替換為開 `<dialog>` 的正式鈕即可，版位
   與 class 命名（`preview-controls__output-placeholder`）已預留。
