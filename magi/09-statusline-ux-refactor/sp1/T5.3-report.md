## 關鍵決策

1. **單一事實來源反轉的落地形**：`segments.ts` 在 `SEGMENT_DESCRIPTOR_LIST`
   定義前新增 `const M = t(DEFAULT_LOCALE)`（模組級快取，非逐段重複呼叫
   `t()`），30 段 `label`／`icon.ariaText` 全數改為 `M.segments['id'].label`／
   `.ariaText` 取值。`messages.test.ts` 既有「zh-Hant 字典抄寫零漂移」測試
   （逐段比對 `t('zh-Hant').segments[id]` 與 `SEGMENT_DESCRIPTORS` 現行字面）
   因反轉而從「兩處手抄需同步」轉為結構性恆真——562 案含此測試綠燈即為
   佐證，未刪測試（保留無妨，PLAN 明文許可）。

2. **locale 感知 accessor 落於 segments.ts（非 resolve.ts）**：新增
   `segmentLabel(id, locale = DEFAULT_LOCALE)`／`segmentAriaText(id, locale =
   DEFAULT_LOCALE)`，兩者皆為 `t(locale).segments[id].*` 的薄轉發（不重複
   維護字典）。選擇放 segments.ts 而非 resolve.ts：descriptor 目錄（消費
   `SegmentId` 型別、與 `DESCRIPTORS_BY_ID` 同層次的查表 API）是自然歸屬層，
   且 PLAN 任務敘述明確指定「segments.ts...新增 locale accessor export」。
   resolve.ts 只 `import { segmentAriaText } from './segments.js'` 消費，
   不重新實作查表邏輯。

3. **resolve.ts 的兩處 aria 組裝點改走 locale**：
   - `headAria`（icon run 的 SR 文字等價）從直讀
     `descriptor.icon.ariaText`（恆 zh-Hant）改為
     `segmentAriaText(descriptor.id, locale)`——此為 PLAN 指名「若能低成本走
     accessor 就走 accessor」的落地，en locale 下預覽 aria 因而真正翻轉
     （見 resolve.test.ts 新增「en：icon run ariaText 走
     segmentAriaText(id,"en")」案，斷言 `'Model Fable 5'` 而非
     `'模型 Fable 5'`）。
   - `↺`→「重置」的字面代換（M6 C4，兩處：`ariaSuffix`／`valueAria`）改為
     `t(locale).resetAriaWord`（`resolveSegment` 頂部算一次 `resetWord`
     共用兩處，避免重複呼叫 `t()`）——en 下代換為 `'reset'`
     （見「en：倒數段 value ariaText 代換詞」「en：percent-reset 後綴」兩案）。
   - `descriptor.label`（腳本輸出／main.ts 直讀欄位）與主值 `text` 通道
     完全不受 `locale` 影響——新增「text 主文字通道不受 locale 影響」案
     顯式鎖死此邊界（僅 aria-label 組裝分岔，emit-bash／emit-ps1 消費面
     零觸碰，golden 鎖綠燈亦為佐證）。

4. **`ResolveInput.locale?: Locale` 選填、預設 `DEFAULT_LOCALE`**：`resolve()`
   / `resolveSegment()` 簽章不變（`locale` 就地讀 `input.locale`，未新增
   函式參數），既有呼叫點（main.ts／render-preview／各測試／golden
   scripts）因而零改動仍編譯——新增「缺省 locale＝顯式 zh-Hant 等價」案
   以 byte 級 `toEqual` 鎖死此相容承諾。

5. **segments.ts :248 過時註解修正**：原「ariaText＝SR 文字等價（中文，
   不受本次變更影響）」改寫為說明欄位值改自 messages.ts zh-Hant 字典、
   locale 感知取值走 `segmentLabel`／`segmentAriaText`（見 segments.ts
   `SegmentDescriptor.icon` 欄位文件；同段落亦覆蓋 `label` 欄，故合併
   一處說明未重複展開）。
