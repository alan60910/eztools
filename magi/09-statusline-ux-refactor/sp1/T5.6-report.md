## 五步序落點（main.ts `handleLocaleSwitch`，語言鈕 click 觸發鏈）

依 PLAN 明訂順序實作，`initLangToggle`（i18n-dom.ts）完成第 (1) 步後以
`onLocaleChanged` callback 交棒：

1. **主樹重套**：`i18n-dom.ts` `initLangToggle` 內 `persistLocale(next)`
   （先持久化，使後續 `currentLocale()` 讀到新值）→
   `applyI18n(document, next)`。
2. **rebuild 中欄 segment rows＋刷新 row-select／目錄項名**
   （`handleLocaleSwitch`）：`buildSegmentRows()`（重跑一次性
   aria/label 賦值）→ `layoutSegmentContainers(computeRowGroups(config.
   segments))`（直接呼叫、不經 `commitConfig` 的 `rowGroupsEqual` 閘
   門——rebuild 產出全新 `<li>`，即使分組結構未變也須無條件重新掛載；
   內部已含 `refreshRowSelects`／`refreshRowNumbering`）→
   `syncFgOverrideDisabled()`（新 picker 節點需重新同步 disabled 態）→
   `refreshCatalogNames()`（新函式：`.catalog-item__name` 為 clone 時
   一次性 textContent，非 data-i18n，需顯式重填；不重建/搬移目錄項節
   點，「目錄項終生不重建」不變量不受影響）。**不涉段列焦點保全**（round
   2 既定，本任務未做任何焦點復原）。
3. **強制 preview 重 resolve**：`preview.setLocale(next)`（render-
   preview.ts 新方法）。
4. **`<html lang>` 翻轉**：`syncHtmlLang(next)`（i18n-dom.ts 新匯出，
   PLAN 明訂排在 rebuild／preview 重 resolve 之後，故不在 `initLang
   Toggle` 的第 (1) 步內完成）。
5. **播報**：`announceGlobal(msg().langToggle.switchedAnnounce)`——切換
   後語言的自我指涉句（無插值），`#global-live-status` 承載。

`config`／`rowSlots` 全程不被 `handleLocaleSwitch` mutate（純視圖重繪，
狀態斷言見測試段）。

## default-hint 結構化改造（收 T5.5「混語形」已知限制）

`segment-defaults.ts`：`SegmentFieldDefaultInfo.defaultLabel: string`
（zh-only 字面）改為 `descriptor: SegmentFieldDefaultDescriptor | null`
——新增 11 種 kind 的結構化描述子（`firstRow`／`iconState`／
`emptyPrefix`／`literalPrefix`／`variant`／`colorDefault`／`colorAuto`／
`colorLiteral`／`noFgOverride`／`noThreshold`／`barState`），**本檔零
messages.ts import**（維持純描述子模組定位）。main.ts 新增
`defaultDescriptorLabel()` 於 render 層以 `t(currentLocale())` 解讀，
多數 kind 複用既有域避免重複——`firstRow`→`rowGroup.heading(1)`、
`variant`→`variantLabel[value]`（缺表退原值）、`colorDefault`/
`colorAuto`→`colorPicker.modeDefault`/`modeAuto`；僅 `iconState`／
`emptyPrefix`／`noFgOverride`／`noThreshold`／`barState` 五類新增
`messages.ts` 的 `defaultDescriptor` 域承載（`iconOn`/`iconOff`/
`emptyPrefix`/`noFgOverride`/`noThreshold`/`barOn`/`barOff`，兩語言）。
`literalPrefix`／`colorLiteral`（ansi256 swatch 名／hex）locale-
invariant，原值直接顯示。segment-defaults.ts 原本地 `VARIANT_LABELS`
zh-only 複製表隨此改造移除（`messages.variantLabel` 收斂為單一事實來
源）。`colorDisplayLabel`（供 T2.2 顯示「現值」與其自身測試）保留不動；
新增 `colorDefaultDescriptor` 內部複用 `colorDisplayLabel` 產生
`colorLiteral.value`。

zh 輸出 byte 一致性：`default-hint.dom.test.ts`（既有、鎖 zh 渲染結果，
斷言的是 DOM textContent 而非本檔介面形狀）**零改動、全數通過**——證明
結構化改造未改變 zh 渲染字面。`segment-defaults.test.ts` 的斷言隨介面
改動同步調整（`defaultLabel: 'X'` → `descriptor: {kind:..., ...}`），
理由已記於該檔新增的檔頭段落。

## render-preview.ts 改動細節（見上方偏離授權說明）

## main.ts 其餘改動

- `buildSegmentRows()` 修正一處**必要前置 bug**（非本任務新增功能本
  身，是讓 rebuild 語意正確運作的必要修復）：舊實作只清空隱藏池
  （`segmentHiddenPoolEl.textContent = ''`），未處理「已啟用段的
  `<li>` 現居列群組容器（非隱藏池）」的情況——語言切換時二次呼叫
  `buildSegmentRows()` 會讓新舊 `<li>` 並存於文件樹（重複 id，
  `querySelector` 命中順序不定，追溯翻轉失敗——**實測抓到**：新測試
  最初 4 案失敗，`segmentRowName('cost')` 讀到切換前的舊值）。修法：
  清空前先 `for (const li of rowElements.values()) li.remove()`，
  init() 首次呼叫時 `rowElements` 為空、此迴圈為 no-op，不影響既有
  行為。
- `initLangToggle` 呼叫改傳 `handleLocaleSwitch` 作 `onLocaleChanged`
  callback；`bootLocale` 的 `<html lang>` 同步改呼叫 `syncHtmlLang`
  （與 i18n-dom.ts 單一事實來源一致，行為不變）。

## 結構化 default-hint 介面定案（供後續參考）

`SegmentFieldDefaultDescriptor`（`segment-defaults.ts` 匯出）：
```ts
type SegmentFieldDefaultDescriptor =
  | { kind: 'firstRow' }
  | { kind: 'iconState'; on: boolean }
  | { kind: 'emptyPrefix' }
  | { kind: 'literalPrefix'; value: string }
  | { kind: 'variant'; value: string }
  | { kind: 'colorDefault' }
  | { kind: 'colorAuto' }
  | { kind: 'colorLiteral'; value: string }
  | { kind: 'noFgOverride' }
  | { kind: 'noThreshold' }
  | { kind: 'barState'; on: boolean }
```
`SegmentFieldDefaultInfo.descriptor: SegmentFieldDefaultDescriptor |
null`（`null` ＝ `applicable: false`，同原慣例）。main.ts
`defaultDescriptorLabel(descriptor): string` 為唯一解讀端。
