# PRD — EZTools

## Problem
日常需要進行圖片／動圖／影片的格式轉換與簡單編輯（如 APNG 轉 GIF、GIF
頁數與停留時間調整、MKV 轉 MP4）時，往往要安裝軟體或使用充斥廣告的線上
服務。EZTools 提供一個純靜態、免安裝、可自行託管於 GitHub Pages 的工具
合集入口頁面。

## Users
<primary users, secondary users, non-users>

## Goals
- 提供入口頁面，列出所有可用工具
- APNG → GIF 等圖片格式轉換功能
- GIF 編輯功能（頁數編輯、時間停留等基礎功能）
- 影片格式轉換功能（如 MKV → MP4）
- 可直接由 GitHub Pages 託管（純靜態、無後端）
