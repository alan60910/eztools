S7 spike：<select> 原地更新的焦點／選取保存 — 最小 repro

這頁面模擬 statusline-builder 中「顯示於第 N 列」下拉選單在使用者持續 新增列時的即時刷新路徑。三種觸發方式：(1) 控制區的 「新增一列」按鈕；(2) 開啟「自動連續更新」 （每 800ms）；(3) 在任一 select 下拉中直接選「新增一列」選項 （比照真實 UI 語意：建新列＋該段改指到新列）。無論哪種觸發，下方全部 <select> 都被原地更新（更新既有 <option> 文字＋在「新增一列」選項之前插入一個新 option），絕不重建 select 或整批替換 option。請先聚焦（點擊或 Tab）任一 select、展開下拉、 用方向鍵移動反白但先別按 Enter，再觸發更新，觀察： (1) 未聚焦的其他 select 是否被搬走焦點／頁面是否跳捲動； (2) 被更新的那個 select（含你正聚焦的那個）更新後顯示值是否仍對應你 原本選的項目。詳細操作腳本見同目錄 TESTING.md；結果請記錄到 RESULTS.md。

（本區塊僅供容器捲動觀察，無互動元素）

三個 select 初始選取值刻意不同（A=第1列／B=第2列／C=第3列），方便肉眼 核對「更新後 selectedIndex／value 是否仍對應原選取」。「事件記錄」 面板記錄 focus／blur／change 與每次更新觸發的時間戳，供交叉核對操作 與畫面反應的先後順序。
