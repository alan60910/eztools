2. 開啟瀏覽器 DevTools → Console 分頁。
3. 用文字編輯器開啟本機檔案
   `tools/statusline-builder/fixtures/reference-7row.json`，全選複製其
   完整內容（本身即合法 JSON 文字，不含反引號）。
4. 在 Console 貼上並執行（以反引號樣板字串包裹貼上內容，避免逐字元跳脫）：

## C. 產出腳本安裝到 Claude Code（真機驗收前置）

Windows 環境建議走 PowerShell 路徑（與 reference 腳本同構）：

1. 於「產出區」找到 `settings.json 內的腳本路徑` 輸入框（欄位 id
   `settings-path`），填入你打算安裝的實際路徑並以 `.ps1` 結尾，例如
   `C:\Users\<你的帳號>\.claude\statusline.ps1`（或沿用預設
   `~/.claude/statusline.ps1`）。
2. 點「下載 PowerShell 腳本」，將下載的 `statusline.ps1` 移動/另存到步驟
   1 填的實際路徑。
3. 點「下載 settings 片段」，開啟下載的 `statusline.settings.json`；將其
   內容中的 `"statusLine": { ... }` 整段，貼入（合併）你的
   `~/.claude/settings.json`（若該檔已有其他鍵，只新增/取代
   `statusLine` 鍵，不要整檔覆蓋）。
4. **MOTW 提醒**：瀏覽器下載的 `.ps1` 會被標記「來自網際網路」。
   settings 片段已用 `-ExecutionPolicy Bypass` wrapper 繞過；若 statusline
   仍空白，於 PowerShell 執行 `Unblock-File <你的 .ps1 路徑>` 或於檔案
   內容 → 內容 → 勾選「解除封鎖」。
5. 開新的 Claude Code 對話（或重啟 Claude Code）使 `settings.json` 生效。

若改用 POSIX（bash）目標：腳本路徑改填如 `~/.claude/statusline.sh`（不
以 `.ps1` 結尾即自動判定 POSIX），下載「bash 腳本」取代步驟 2，並執行
`chmod +x ~/.claude/statusline.sh` 賦予執行權限（步驟 4 的 MOTW 不適用）。

- [ ] `settings.json` 內 `statusLine.command` 指向正確路徑
- [ ] 新對話中 statusline 出現、非空白、無錯誤訊息殘留於畫面
