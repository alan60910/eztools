# 授權聲明 — symbols-nerd-font-mono-subset.woff2

本目錄之 `symbols-nerd-font-mono-subset.woff2` 為
**Symbols Nerd Font Mono**（[ryanoasis/nerd-fonts](https://github.com/ryanoasis/nerd-fonts)
v3.4.0 release 資產）之 28-glyph 子集（Modified Version）。子集內全部
字形輪廓來自兩個 MIT 授權之上游 glyph 集（經 nerd-fonts 聚合）：

- **Powerline Symbols** ×5（U+E0A0、U+E0B0–E0B3）—
  [powerline/powerline](https://github.com/powerline/powerline)，MIT，
  Copyright 2013 Kim Silkebækken and other contributors
- **Octicons** ×23（U+F400 區）—
  [primer/octicons](https://github.com/primer/octicons)，MIT，
  Copyright (c) GitHub Inc.
